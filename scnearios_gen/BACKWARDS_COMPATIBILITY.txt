📝 CODE EXAMPLES

  EXAMPLE 1: Original Interface (Works Exactly the Same)
  ──────────────────────────────────────────────────────

    from k8s_cluster_generator_enhanced import K8sClusterGenerator, UseCase

    # This is IDENTICAL to original usage
    generator = K8sClusterGenerator(
        num_nodes=10,
        use_case=UseCase.MICROSERVICES,
        seed=42
    )
    
    cluster = generator.generate()
    
    # Output format is the same
    print(cluster['cluster_metadata']['total_services'])
    print(cluster['services'])
    print(cluster['service_instances'])


  EXAMPLE 2: Enhanced Features (Optional - Use When Needed)
  ──────────────────────────────────────────────────────────

    from k8s_cluster_generator_enhanced import (
        EnhancedK8sClusterGenerator,
        ClusterDynamicConfig,
        SubnetConfig,
        NetworkTopologyConfig,
        UseCase
    )

    # Use enhanced features for advanced scenarios
    config = ClusterDynamicConfig(
        num_nodes=20,
        use_case=UseCase.MICROSERVICES,
        subnet_config=SubnetConfig(
            subnet_ranges=[1, (2,4), (3,6)],
            subnet_labels={1: "dmz", 2: "app", 3: "db"}
        ),
        network_topology=NetworkTopologyConfig(
            topology_type="hub_spoke"
        )
    )
    
    generator = EnhancedK8sClusterGenerator(config)
    result = generator.generate()

❓ FAQ

  Q: Do I need to change my existing code?
  A: No. Just update the import statement. Everything else stays the same.

  Q: Will my existing configurations still work?
  A: Yes. All original configurations work without modification.

  Q: Can I mix original and enhanced interfaces?
  A: Yes. Use K8sClusterGenerator for simple cases, 
      EnhancedK8sClusterGenerator for advanced scenarios.

  Q: What if I don't need the enhanced features?
  A: No problem. Use it exactly like the original. Enhanced features
      are optional.

  Q: How do I verify compatibility?
  A: Run: python test_backwards_compatibility.py

  Q: Are there any breaking changes?
  A: No. Zero breaking changes. 100% backwards compatible.
